# zar3a, feature-based MVVM

Start with README-AR.md for setup, the folder map, an Arabic walkthrough, course mapping and the exact test/build limits. Source is under lib/, tests under test/, rendered phone previews under previews/.

Flutter 3.50.1 / Dart 3.14.0 verified. Run `flutter pub get`, `flutter test`, then `flutter run`.

This includes the introduction and local login/sign-up/verification UI. It has no real backend, authentication session or background location tracking. Named Navigator routes intentionally replace go_router to stay with the supplied course. No GitHub changes were made.
